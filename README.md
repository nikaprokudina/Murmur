# Murmur Website

Static support and legal website for the Murmur iOS app.

## Files

- `index.html` - product landing page
- `support.html` - support contact page
- `privacy.html` - Privacy Policy
- `terms.html` - Terms of Service
- `style.css` - shared site styles
- `robots.txt` - crawler rules
- `sitemap.xml` - sitemap for GitHub Pages
- `assets/` - local app imagery copied from the Murmur repository

## App Store metadata URLs

Use these URLs after publishing this folder with GitHub Pages or another static host:

- Privacy Policy: `https://nikaprokudina.github.io/water_tracker_web/privacy.html`
- Terms of Service: `https://nikaprokudina.github.io/water_tracker_web/terms.html`
- Support: `https://nikaprokudina.github.io/water_tracker_web/support.html`

## Notes

The legal pages reflect the app code reviewed on August 16, 2026: local storage, no accounts, no analytics or advertising SDKs, local notifications, and optional support email.
